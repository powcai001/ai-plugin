# Personal AI Plugin

个人 AI Plugin 集合，统一管理可供 Codex、Claude Code、CC Switch 及兼容工具使用的内容。

```text
ai-plugin/
├── skills/
├── agents/
├── rules/
├── commands/
├── hooks/
└── mcp/
```

在 CC Switch 中添加 GitHub 仓库 `https://github.com/powcai001/ai-plugin` 作为同步源。仓库为私有，需要 CC Switch 所在环境具备 GitHub 访问权限。

`siyuan-note` 使用 `SIYUAN_API_TOKEN` 或 `--token` 提供 API token；不要把真实 token 提交到仓库。

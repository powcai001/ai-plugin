# 文章格式模板

用于编辑完成后的输出。根据用户需求选择最小格式，不要每次都输出所有部分。

## 默认：只给成稿

用户只说「帮我润色」「改一下」「编辑检查」时，默认输出最终文章：

```markdown
# [标题]

[编辑后的正文]
```

## 带修改建议

用户要求检查、点评、指出问题，或文章有明显结构问题时：

```markdown
# [标题]

[编辑后的正文]

---

## 修改建议

- [建议 1]
- [建议 2]
- [建议 3]
```

## 只做审稿

用户说「先别改，帮我看看」时：

```markdown
## 阅读体验问题

- ...

## 结构问题

- ...

## 表达问题

- ...

## 最值得改的 3 处

1. ...
2. ...
3. ...
```

## 长文格式

长文可以自然使用：

```markdown
# [标题]

[开头]

---

## [具体小标题]

[正文]

---

## [具体小标题]

[正文]
```

分章节是为了阅读体验，不是硬性模板。短文不要强行加标题。

## 重点标注

自然需要时使用：

- `**加粗**`：强调关键判断或关键词。
- `>` 引用块：让一句核心观点独立出现。
- 列表：帮助读者快速扫重点。

不要强制每节标注。

# 研究素材整理模板

用于把语音中出现的观点，延展成可供后续写作使用的素材。

## 素材类型

### 理论

- 心理学：认知偏差、动机、注意力、习惯形成。
- 管理学：组织协作、决策、激励、流程。
- 经济学：激励、成本、市场结构、信息不对称。
- 社会学：群体、阶层、制度、文化。
- 认知科学：记忆、学习、模型、判断。

### 数据

优先级：

1. 官方统计。
2. 研究论文。
3. 权威报告。
4. 行业报告。
5. 媒体报道中的二手数据。

标注可信度：高 / 中 / 待核查。

### 案例

- 商业案例。
- 历史事件。
- 名人故事。
- 企业实践。
- 身边人的真实场景。

案例必须服务观点，不要为了热闹而堆案例。

### 表达素材

- 类比。
- 比喻。
- 可引用观点。
- 简洁句子。
- 反直觉表达。

## 输出格式

```markdown
## 理论

- 名称：...
  - 说明：...
  - 可用于说明：...
  - 可信度：...

## 数据

- 数据：...
  - 来源：...
  - 年份：...
  - 可信度：...
  - 用法：...

## 案例

- 案例：...
  - 背景：...
  - 关键细节：...
  - 能说明什么：...
  - 风险/争议：...

## 表达素材

- 句子/类比：...
  - 适合放在哪里：开头 / 过渡 / 结尾 / 小标题
```

## 联网时

联网得到的信息必须区分：

- 已核实：来源明确，可直接引用。
- 待核查：来源不足或存在争议。
- 灵感素材：只提供方向，不作为事实引用。

不要把未核实的信息写成确定事实。

# 选题孵化模板

用于把语音灵感从「想到什么说什么」整理成可写选题。

## 多主题识别

如果用户同时谈到多个主题，先拆开：

| 主题 | 一句话总结 | 情绪/动机 | 可写性 |
|---|---|---|---|
| A | ... | ... | 高/中/低 |

不要急着合并。很多好文章来自其中一个支线，而不是用户开头说的主题。

## 四把尺子

| 尺子 | 高分表现 | 低分表现 |
|---|---|---|
| 相关性 | 回应用户真正关心的问题 | 只是顺手提到 |
| 时间尺度 | 长期可复用、可反复讨论 | 只适合今天吐槽 |
| 研究贡献 | 提供新理解、新方法、新框架 | 只是重复常识 |
| 与福祉的距离 | 能帮助人做判断、改善生活/工作 | 只是在表达情绪 |

## 思考完善问题

- 这个判断的证据是什么？
- 有没有反例？
- 是否把相关性当成因果？
- 是否只看到了成功样本？
- 有没有概念混用？
- 如果站在反方，会怎么反驳？
- 这个问题更深层的结构是什么？
- 读者为什么需要知道这件事？

## 大纲选择

不要固定模板。根据选题选择：

- 观点型：现象 → 判断 → 例子 → 反思。
- 方法型：问题 → 原因 → 做法 → 注意事项。
- 复盘型：背景 → 尝试 → 结果 → 教训。
- 研究型：TAIMRDR。
- 轻短文：一个观察 → 一句判断 → 一个例子 → 一句收束。
